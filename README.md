# Contador de dedos con MediaPipe

**Ejercicio Módulo 01 · Interacción Natural (NUI) y Visión por Computadora**
Taller de Diseño de Interfaces, Universidad Adolfo Ibáñez, 2026 · Pedro Claro

▶️ **Probar:** https://pclarow.github.io/mediapipe-manos/

La cámara detecta la mano con **MediaPipe Hand Landmarker**, dibuja sus 21 puntos y cuenta cuántos dedos están levantados (puño, uno, paz, tres, cuatro, mano abierta).

## Uso
1. Abrir en Chrome, presionar **Activar cámara** y aceptar el permiso.
2. Mostrar una mano frente a la cámara.

## Tecnologías
- `@mediapipe/tasks-vision` (Hand Landmarker, modo VIDEO)
- Canvas 2D para el video en espejo y el esqueleto
- GitHub Pages
